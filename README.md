# 净帧 ClearFrame

[打开在线工具](https://ouweikang000910.github.io/clearframe-studio/)

图片和视频去水印网页。无需注册、无需 API Key，素材在浏览器本地处理，不上传到服务器。

## 使用

1. 选择“图片去水印”或“视频去水印”，上传或拖入素材。
2. 在画面上拖动框选水印，可添加最多 8 个区域。
3. 选择周边修补、模糊遮盖，或框选保留区域进行裁剪。
4. 实时查看处理效果，按住“查看原图”对比，然后导出并下载。

## 格式和限制

- 图片：PNG / JPG / WebP，最大 40 MB、2400 万像素；可导出 PNG / JPG / WebP。
- 视频：浏览器可解码的 MP4 / MOV / WebM，最大 300 MB、最长 3 分钟、最高 4K。
- 视频保留原声，使用浏览器编码器，优先 MP4，回退 WebM。视频编码按播放时长进行，导出时保持页面在前台。
- 支持原始尺寸或限制最长边为 1920 / 1280 px。

周边修补使用四侧边界色彩插值，适合天空、墙面等简单背景。复杂纹理可能留下痕迹；当前没有 AI 内容重建或移动水印追踪。视频实际帧率受设备性能影响。请使用自己拥有或已获授权的素材。

显示字体 Archivo Black 随网页本地加载，附带 OFL 开源授权；图片和视频始终只在本地处理。

## 本地运行

```sh
python3 -m http.server 8788 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8788/ 。无需安装 npm 依赖。

## 开发检查

```sh
node --check app.js
node tests/repair.test.cjs
```

已在桌面 Chromium 中验证 PNG 导出、JPG 裁剪、撤销、恢复、视频导出与取消。4 秒 640×360 测试视频成功导出 H.264 MP4 + AAC，时长约 4.01 秒，音频非静音。390 px 手机布局无横向溢出；未实测 Safari 和手机视频编码。

## 部署

纯静态网页，GitHub Pages 从 `main` 分支根目录发布。更新 HTML / CSS / JavaScript 文件后会自动重新部署。

## 2026-10-24 视觉改版

采用已确认的暗红、墨绿、奶油黄与超粗字设计。示例人像为专门生成的演示素材，右下角 SAMPLE 字样由画布添加，便于体验框选修补。上传自己的素材后不叠加示例水印。显示字体及其 OFL 授权位于 `assets/`（Sites 源码中为 `dist/assets/`）。处理算法与文件大小限制保持原有行为。
